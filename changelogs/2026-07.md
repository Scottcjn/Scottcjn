# Elyan Labs Changelog — July 2026

The monthly digest of what actually shipped across the RustChain / BoTTube / agent ecosystem. Sporadic-looking bursts, organized. Previous months: this is the first one; the cadence starts here.

## TL;DR

Consensus docs and emission policy locked to RIP-0004 (fixed 1.5 RTC/epoch, no halving). UTXO integrity and payout-pipeline hardening across the board. POWER8 VSX kernels merged upstream into an external project at 12.8x scalar. The ecosystem got its unicorn packaging: live leaderboard site, manifesto, ecosystem map, agent quickstart, and a coherent licensing policy.

## RustChain core

- **Emission policy settled**: docs corrected to fixed 1.5 RTC/epoch per RIP-0004 — no halving schedule ([#7830](https://github.com/Scottcjn/Rustchain/pull/7830), [#7970](https://github.com/Scottcjn/Rustchain/pull/7970))
- **`/api/tokenomics` implemented** + docs accuracy pass ([#7922](https://github.com/Scottcjn/Rustchain/pull/7922))
- **UTXO integrity**: dual-write rollback fix + mempool storage normalization ([#7928](https://github.com/Scottcjn/Rustchain/pull/7928)); account-mirror boxes refused via `/utxo/transfer` while dual-write is off ([#8006](https://github.com/Scottcjn/Rustchain/pull/8006))
- **Consensus correctness**: sub-1.0 penalty multipliers preserved in time-aged multiplier calc ([#7925](https://github.com/Scottcjn/Rustchain/pull/7925))
- **BCOS**: fair scoring, ledger anchor endpoint, attest epoch, rustchain.org routing ([#7890](https://github.com/Scottcjn/Rustchain/pull/7890))
- **RIP-0311 proposed**: scarcity-weighted reward distribution with tenure and identity-cap ([rustchain-rips#12](https://github.com/Scottcjn/rustchain-rips/pull/12))
- macOS serial binding fallback detection fixed ([#7927](https://github.com/Scottcjn/Rustchain/pull/7927))

## Inference & vintage hardware

- **Upstream win**: POWER8 VSX integer-dot kernels merged into [JustVugg/colibri](https://github.com/JustVugg/colibri) — **12.8x int8, 7.6x int4 over scalar** ([#98](https://github.com/JustVugg/colibri/pull/98)), plus the ppc64le build fix ([#97](https://github.com/JustVugg/colibri/pull/97)), validated on the S824
- **rpi-inference dual-brain stack**: engine speedups, multi-stream, cross-vendor speculative decoding ([#173](https://github.com/Scottcjn/rpi-inference/pull/173))
- **exo-cuda interweave**: unified GPU matmul offload server replaces ~20 prototypes, native CUDA server published with CI ([#30](https://github.com/Scottcjn/exo-cuda/pull/30), [#31](https://github.com/Scottcjn/exo-cuda/pull/31))
- **gigatoken POWER8 tier**: VSX tokenizer branch — single-thread 62→209 MB/s (3.37x), 1.62 GB/s on 7 cores, exact invariant preserved ([gigatoken](https://github.com/Scottcjn/gigatoken))
- llama-cpp-tigerleopard: build-from-source guidance for real hardware ([#27](https://github.com/Scottcjn/llama-cpp-tigerleopard/pull/27))
